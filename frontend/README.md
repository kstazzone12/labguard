# Interfaz

Interfaz inicial de LABGUARD con React, TypeScript y Vite. La pantalla actual es únicamente un punto de entrada visual; todavía no consulta datos ni ejecuta validaciones.

## Iniciar

Desde la raíz del repositorio:

```bash
npm --prefix frontend install
npm --prefix frontend run dev
```

La aplicación queda disponible en `http://localhost:5173/`. Vite está configurado para escuchar en `0.0.0.0:5173`, necesario en contenedores y entornos remotos.
